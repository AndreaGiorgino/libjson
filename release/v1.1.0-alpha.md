# libjson v1.1.0-alpha

> [!IMPORTANT]
> This version should not be used since the library is still in development

## Release notes

- json decoding/encoding
- json read/write interface
- Testing framework implementation

## ABI

### `class libjson::json`

Name     | Description
:------- | :------------
`has_value`         | Check if a value is being stored
`as`                | Get the stored value and convert it to a target type
`holds_alternative` | Check if the stored value is of the target type
`at`                | Get a reference to the element in the stored array/object
`operator[]`        | Get a reference to the element in the stored array/object
`push_back`         | Add data to the end of the stored array
`insert`            | Add data to the stored object

### `namespace libjson::extra`

Name     | Description
:------- | :------------
`decode` | Decode json from istream/string
`encode` | Encode json into ostream/string

## Example

```cpp
#include <iostream>

#include "libjson/extra/decode.hxx"

using namespace libjson;

auto main(int, char**) -> int {
    const char* raw {R"(
    {
        "name": "John Smith",
        "age": 25,
        "city": {
            "name": "London"
        }
    }
    )"};

    auto node {libjson::decode(raw)};

    // example usage
    std::cout << node["name"] << " from " << node["city"]["name"] << ", is "
              << node["age"] << " years old." << std::endl;

    return 0;
}
```
