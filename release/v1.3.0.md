# libjson v1.2.0

## Release notes

- CMake declared name updated from `json` to `libjson`

### Usage

```cmake
# CMakeLists.txt

# ...

# Declaring the package

include(FetchContent)

FetchContent_Declare(
    libjson
    GIT_REPOSITORY git@github.com/AndreaGiorgino/libjson
    GIT_TAG 1.3.0
    GIT_SHALLOW TRUE
)

# ...

# Linking the library

target_link_libraries(
    ${PROJECT_NAME}
    PRIVATE libjson
)
```
